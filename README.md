# Flappy-Red Создаём игру апи бёрд
Основные правила этой игры:
птица летит и при нажатии прыгает
колонны поднимаются вверх и опускаются вниз иногда они просто ждут когда ты перелетишь их и они не двигаются по вертикали но движутся по горизонтали
если птица касается колонны то ты проигрываешь
птица будет Пукека и она будет круглая а не в полном размере
и с каждой перепрыгнутой колонны счёт будет изменятся на 1
цель игры:долететь до 1000

Проблема: Писать много кода,птица может проходить в колонны, скорость будет слишком большая или слишком медленная,колонны будут исчезать,гравитация будет слишком большая или маленькая,хитбоксы будут слишком большие

План:
1 Птица будет находится в середине и на ней будет круглая текстура (width/4,height/2)
1.2 Сделать хитбокс птицы
2 Сделать так чтоб при  нажатии на кнопку стрелочка вверх птица прыгала
2.1 потом спускалась из за гравитации
3 Сделать препятствия в нашем случае колонны зелёного цвета которые будут медленно плыть по горизонтали колонны будут сверху и с низу и между ними дырка
3.1 при касании птицы колонны игра закончится
4 сделать счёт и при каждой пройденной колонны добавлять +1
4.1 при касанию колонны счёт будет обнулятся
5 добавить фон
6 добавить паузу
7 всё протестить
